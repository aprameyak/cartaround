# CartaAround

Transparent VC deal data for founders. Log your funding terms and see market benchmarks.

## Features

- Log funding rounds with valuation and equity
- Filter by stage (Seed, Series A, Series B)
- View median valuations and average equity terms
- Benchmark your deal against similar stage

## Quick Start

```bash
npm install && npm start
```

Open `index.html`. API on port 3004.
